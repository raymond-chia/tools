# 戰鬥

- [x] WASD 移動鏡頭
- [x] 滾輪縮放鏡頭
- [x] 右鍵顯示單位屬性
  - 第一次選擇單位會顯示
  - 第二次選擇同單位會取消
  - 第二次選擇不同單位會切換顯示
  - 屬性面板不要擋住右鍵
  - 要即時更新
- [ ] 右鍵顯示物件屬性
- [x] 右鍵先檢查是否切換顯示的單位屬性，然後才檢查是否取消現在的技能
- [x] 左側顯示回合順序
  - 下到上
  - 越下面越接近行動
  - 最下面是目前行動單位
  - 上方可以超出螢幕
  - 要能捲動還沒行動的單位
    - 能拖動頭像來上下捲動
  - 左鍵點選單位，會移動鏡頭
    - 選擇後還需要 highlight 單位 (可以用右鍵的那個 highlight)
    - 如果右側正在顯示單位屬性，也要換成左邊選擇的單位
- [ ] 延後回合
- [x] 沒有選擇技能的時候，就是移動

  - 預覽移動路徑
    - 按照移動範圍，分成兩種顏色
  - 移動時、移動後正確朝向

  - 選取多目標
  - 預覽技能效果、命中、格擋、閃避、爆擊機率
- [x] 左鍵目標格，會施放技能
  - 錯誤處理
    - 沒選單位導致施放失敗，應該要能繼續移動 or 重新施放
    - 根據 error code 找多國語言
  - 施放時、施放後正確朝向
