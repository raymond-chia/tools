# Godot 操作測試方式

## 引擎內輸入測試

載入真實場景，使用 `Viewport.push_input()` 將滑鼠事件送到指定 Viewport 座標，再檢查場景狀態與節點屬性。

- 能測到：Godot GUI 輸入傳遞、場景縮放與座標轉換、操作邏輯，以及節點的顯示、位置和樣式狀態。
- 不能測到：作業系統滑鼠、視窗焦點與 DPI 整合，也不能單靠狀態斷言證明最終像素正確。

## 系統層操作測試

啟動實際遊戲視窗，以桌面自動化工具移動系統游標並點擊指定螢幕座標。

- 能測到：從作業系統輸入、視窗焦點、DPI 與視窗座標，到 Godot 操作結果的完整流程。
- 不能測到：程式內部狀態，除非另外提供觀測方式；測試也容易受桌面環境干擾。

## 像素比對測試

執行操作並等待畫面完成渲染，再擷取 Viewport 或遊戲視窗，與基準圖片比較。

- 能測到：玩家實際看到的選取標記、文字、顏色、遮擋、裁切與版面結果。
- 不能測到：造成差異的內部原因；結果也可能受字型、反鋸齒、renderer 與平台差異影響。
